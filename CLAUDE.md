# Project Instructions

## Objective
Build a reliable, free cloud-based software development environment.

## Working rules
1. Inspect the repository before making changes.
2. Read README.md and PROGRESS.md.
3. Work on one task at a time.
4. Use simple, maintainable solutions.
5. Test every change where possible.
6. Update PROGRESS.md after each completed task.
7. Preserve existing working features.
8. Never claim completion without verification.

## Safety
- Budget: ₹0.
- Never activate paid services.
- Never expose passwords or credentials.
- Never bypass authentication or usage limits.
- Never delete unrelated files.
- Ask before external actions.

## Recovery
1. Inspect Git status.
2. Read PROGRESS.md.
3. Identify the last completed task.
4. Resume from the next incomplete task.

## Reporting
Record completed tasks, files changed, tests,
errors and the next task.
